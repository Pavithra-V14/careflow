# AI drafts for owner review

Every file here is an **AI DRAFT. Not legal advice, not clinical advice, not approved.** Each one is written from `BUILD-SPEC.md` and from what the system already does. Every figure or sentence the spec does not give is a bracketed `[OWNER/COUNSEL: ...]` blank, never a guess. Nothing here is loaded by the application; the owner copies approved text into the settings named in each file.
